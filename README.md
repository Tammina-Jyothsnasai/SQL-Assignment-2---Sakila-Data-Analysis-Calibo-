This repository contains my **SQL Assignment 2**, completed using the **MySQL Sakila sample database**. The assignment progresses from database schema changes and data manipulation to advanced SQL analytics.

## 📌 Repository Overview

The assignment focuses on practical SQL operations performed on the Sakila database, including:

- DDL and schema design
- Data type conversion
- INSERT, UPDATE, DELETE
- Filtering and SQL operators
- INNER, LEFT, RIGHT, SELF and CROSS JOINs
- FULL OUTER JOIN simulation using `UNION`
- Aggregate functions
- `GROUP BY` and `HAVING`
- Subqueries and correlated subqueries
- `EXISTS` / `NOT EXISTS`
- Window functions
- CTEs
- Running totals and ranking
